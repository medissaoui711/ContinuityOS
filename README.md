## 📌 Short Description | وصف مختصر

**AR:** **منظومة استمرارية الأعمال وإدارة الفروع والمكاتب الإدارية (BCM Command Center)** هي منصة قيادية متكاملة صُممت للرؤساء التنفيذيين والمدرة التنفيذيين لضمان الشفافية الكاملة والتحكم المطلق بجميع الفروع، المكاتب الإدارية، الموظفين، وحالة الحضور والانصراف المباشرة (نقاط خضراء/حمراء)، مع تفعيل آلي لخطط البدلاء والتعافي من الكوارث وفق المعايير الدولية ISO 22301.

**EN:** **BCM Command Center & Executive Operations Hub** is an enterprise-grade Business Continuity Management (BCM) and Office Operations platform engineered for C-Level executives and Ops leaders. It delivers 100% real-time visibility over corporate headquarters, regional branches, administrative offices, live attendance indicators (green/red presence dots), and automated proxy delegation engines compliant with ISO 22301.

## 🌟 Executive Key Features | الميزات الرئيسية للمنظومة

### 🏛️ 1. إدارة المكاتب الإدارية والفروع | Administrative Office & Branch Governance
* **AR:** إحاطة شاملة بالمقر الرئيسي (HQ) والفروع الخارجية، توزيع المكاتب الإدارية بالطوابق، وتحديد الطاقة الاستيعابية والمسؤول المباشر عن كل مكتب.
* **EN:** Full oversight of Corporate Headquarters (HQ) and branches, hierarchical office distribution across floors, capacity tracking, and assigned office managers.

### 🟢 2. قسم الحضور والغياب المباشر | Real-Time Attendance & Presence Grid
* **AR:** مؤشر بصري مباشر لكل موظف داخل مكتبه:
  * 🟢 **نقطة خضراء:** موظف حاضر بمكتبه مع وقت التوقيع الإلكتروني.
  * 🔴 **نقطة حمراء:** موظف غائب، مع عرض اسم البديل القائم بالعمل فوراً لضمان عدم توقف الخدمات.
  * 🔵 **نقطة زرقاء:** عمل عن بعد معتمدة.
  * 🟠 **نقطة برتقالية:** إجازة رسمية معتمدة.
* **EN:** Real-time visual presence indicators for staff at their designated desks:
  * 🟢 **Green Dot:** Present at desk with dynamic timestamp.
  * 🔴 **Red Dot:** Absent, automatically displaying the designated active substitute to prevent operational disruption.
  * 🔵 **Blue Dot:** Authorized Remote Work.
  * 🟠 **Amber Dot:** Approved Annual/Medical Leave.

### 🔄 3. مصفوفة الصلاحيات والبدلاء التلقائية | Succession & Role Matrix
* **AR:** تعيين بديل أول وبديل ثاني لكل منصب قيادي أو تشغيلي حرج، مع متابعة نسبة جاهزية وتدريب البديل وتفعيل التفويض بضغطة زر.
* **EN:** Primary and secondary substitute delegation for every critical role, featuring substitute training readiness ratios and instant mandate activation.

### 🚨 4. نظام التعافي وتفعيل طوارئ BCP | Disaster Recovery & Emergency Trigger
* **AR:** تفعيل وضع الطوارئ الشامل بنقرة واحدة، تحويل المعاملات تلقائياً إلى الفروع البديلة، وتتبع بروتوكولات الاستمرارية ISO 22301.
* **EN:** One-click enterprise emergency activation, auto-routing workflows to recovery sites, and auditing BCP protocols compliant with ISO 22301.

### 🔒 5. الخزينة الرقمية الآمنة والسجلات | Digital Vault & Audit Trail
* **AR:** حفظ المشفر لكلمات المرور الحساسة، التراخيص، والعقود، مع سجل تدقيق غير قابل للتعديل لكل إجراء يطاله النظام.
* **EN:** Encrypted storage for critical credentials, licenses, and contracts, backed by an immutable, timestamped audit log.

## 🚀 Getting Started | خطوات التشغيل والتطوير

### Prerequisites | المتطلبات الأساسية
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher

### Installation Steps | خطوات التثبيت

```bash
# 1. Clone the repository | استنساخ المستودع
git clone https://github.com/your-org/bcm-command-center.git

# 2. Navigate to project directory | الانتقال لمجلد المشروع
cd bcm-command-center

# 3. Install dependencies | تثبيت الاعتمادات
npm install

# 4. Start Development Server | تشغيل خادم التطوير
npm run dev
```

The application will be accessible at: `http://localhost:3000`

## 💻 Usage & Workflows | طريقة الاستخدام والعمليات

1. **الاطلاع على النظرة الشاملة (Executive Overview):**
   افتح الشاشة الرئيسية لمتابعة نسبة الجاهزية التشغيلية للشركة، الفروع المفعّلة، ومعدل حضور الكادر المباشر.
2. **إدارة المكاتب الإدارية (Office Management):**
   انتقل إلى تبويب **"المكاتب الإدارية والفروع"** لاستعراض كافة الفروع (المقر الرئيسي، فرع الريان، فرع اللؤلؤة)، وإضافة مكاتب جديدة وتوزيع الطاقة الاستيعابية.
3. **توقيع الحضور والانصراف المباشر (Live Attendance Check-In):**
   انتقل إلى تبويب **"إدارة الموظفين والحضور"**، حيث يمكن تسجيل حضور الموظفين بضغطة زر فتتحول النقطة إلى **خضراء 🟢** مع توقيع وقت الحضور، أو تسجيل الغياب فتتحول إلى **حمراء 🔴** مع عرض اسم الموظف البديل فوراً.
4. **تفعيل خطط الاستمرارية والتفويض (BCP Delegation):**
   في حال غياب أي قيادي، يقوم النظام آلياً بمنح التراخيص والموافقة للبديل المعتمد لضمان استمرارية المعاملات دون تأخير.
